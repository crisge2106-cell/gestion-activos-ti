Importar especificaciones técnicas (desde script PowerShell)

Ejecuta Get-EquipoSpecs.ps1 en la máquina del trabajador. Genera un archivo JSON con marca, modelo, serie, procesador, RAM y almacenamiento. Impórtalo aquí: si el número de serie coincide con un equipo del inventario, se completan sus specs; si no existe, se crea un equipo nuevo.
